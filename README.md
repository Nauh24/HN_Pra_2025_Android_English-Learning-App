
# HN_Pra_2025 Android — English Learning App

A lightweight Android app for learning English vocabulary by course and lesson. Browse courses, study lesson words (definition, example, pronunciation), take quick tests, and track your progress.

Key features

- Course list with Ongoing / Completed status
- Lesson cards showing cover image, progress bar, and learned word count
- Lesson detail with vocabulary list and audio pronunciation
- Word details / flashcards: word, phonetic, part of speech, definition, example
- Test mode: prompt by definition or audio, input answer, immediate feedback and correct answer
- Personal progress: learned word count, progress visuals, weekly study tracking
- Profile: language toggle, notification settings, logout, account removal
- Daily learning reminders with configurable time
